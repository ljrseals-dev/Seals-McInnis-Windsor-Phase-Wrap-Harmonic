# SMWPWH Examples

Five short studies demonstrating the Seals–McInnis–Windsor Phase-Wrap Harmonic.

| File | Title | Concept |
|---|---|---|
| `ouroboros-phase-canon.ly` | Ouroboros Phase Canon | Two-voice phase canon at φ=1/2 |
| `phase-cadence.ly` | Phase Cadence | Three voices converge to φ=0 |
| `risset-glissando.ly` | Endless Rise | Continuous Shepard–Risset glissando |
| `phase-fugue.ly` | Phase Fugue | Subject, answer, countersubject in phase |
| `phase-unison.ly` | Phase Unison | Prepared and resolved phase unison |

## Building

```bash
lilypond ouroboros-phase-canon.ly
lilypond phase-cadence.ly
lilypond risset-glissando.ly
lilypond phase-fugue.ly
lilypond phase-unison.ly
